  1. 01

    CSS laden

    Styles einbinden und das HTML-Snippet an der gewünschten Stelle platzieren.

    <link rel="stylesheet" href="copy-button.css">
  2. 02

    Den Kopier-Button aktivieren

    Das Script nach dem Komponenten-HTML laden und die Instanz erstellen.

    <script src="copy-button.js"></script>
<script>
const copy = new CopyButton(document.querySelector('[data-jd-copy]'));
</script>
  3. 03

    Deinen Text verbinden

    Den Text in data-copy-value ersetzen oder später aus deinem Projekt setzen.

    copy.setText('Dein Code, Link oder Gutschein');
  4. 04

    Direkt verwenden

    HTTPS oder localhost für die Clipboard-API verwenden. Tastatur, Rückmeldung und ein manueller Fallback sind bereits eingebaut.
